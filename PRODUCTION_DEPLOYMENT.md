## Step-by-Step Deployment

### Phase 1: Prepare & Push to GitHub

#### 1.1 Verify Everything is Committed

```bash
# From project root
git status
# Should show "nothing to commit, working tree clean"
```

#### 1.2 Final Commit

```bash
git add -A
git commit -m "chore: production-ready refactored backend and frontend for Koyeb and Vercel"
git push origin main
```

Or if your default branch is `master`:
```bash
git push origin master
```

---

### Phase 2: Deploy Backend (Koyeb - Free Tier)

#### 2.1 Create Koyeb Account
- Go to [koyeb.com](https://koyeb.com)
- Sign up (no credit card required)
- Verify email

#### 2.2 Create New App on Koyeb

1. **Click "Create App"**
2. **GitHub Integration**
   - Select "GitHub"
   - Authorize Koyeb access to your repositories
   - Select your `devlinks` repository
3. **Builder Settings**
   - Builder: "Dockerfile"
   - Dockerfile path: `Dockerfile`
   - Build context: `.` (root)
4. **Instance Settings**
   - Instance type: "Free"
   - Region: Closest to you
5. **Environment Variables** (Add these in Koyeb dashboard)
   ```
   POSTGRES_URL=postgresql+asyncpg://user:pass@host/db
   MONGO_URL=mongodb+srv://user:pass@host/db
   REDIS_URL=redis://host:port
   SECRET_KEY=your-32-char-minimum-secret-key
   BASE_URL=<auto-generated-koyeb-url>
   CORS_ORIGINS=https://your-vercel-frontend.vercel.app
   ```
6. **Port**: 8080 (Koyeb default)
7. **Click Deploy**

#### 2.3 Wait for Deployment

Koyeb will:
1. Clone your repo
2. Build Docker image
3. Start container
4. Show you a public URL like: `https://devlinks-abc123.koyeb.app`

Copy this URL — you'll need it for the frontend!

#### 2.4 Run Migrations (One-time)

After deployment, run migrations on production database:

```bash
# Using Koyeb shell
koyeb ssh devlinks-main
# Then inside container:
alembic upgrade head
```

Or via curl once deployed:
```bash
curl https://devlinks-abc123.koyeb.app/health
```

---

### Phase 3: Deploy Frontend (Vercel - Free Tier)

#### 3.1 Create Vercel Account
- Go to [vercel.com](https://vercel.com)
- Sign up with GitHub
- Authorize GitHub integration

#### 3.2 Import Project

1. **Click "Add New" → "Project"**
2. **Import Git Repository**
   - Select your `devlinks` repository
   - Click "Import"
3. **Configure Project**
   - **Project Name**: `devlinks`
   - **Framework Preset**: "Vite"
   - **Root Directory**: `./frontend`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
4. **Environment Variables**
   Add these in Vercel dashboard (Settings → Environment Variables):
   ```
   VITE_API_BASE_URL=https://devlinks-abc123.koyeb.app
   VITE_FIREBASE_API_KEY=your-firebase-key
   VITE_FIREBASE_AUTH_DOMAIN=your-firebase-domain
   VITE_FIREBASE_PROJECT_ID=your-firebase-project
   ```
5. **Click Deploy**

#### 3.3 Wait for Build

Vercel will:
1. Clone repo
2. Install dependencies
3. Build frontend (`npm run build`)
4. Deploy to CDN
5. Show you a URL like: `https://devlinks-abc123.vercel.app`

#### 3.4 Update Backend CORS

Go back to Koyeb dashboard and update the `CORS_ORIGINS` environment variable with your Vercel URL:

```
CORS_ORIGINS=https://devlinks-abc123.vercel.app
```

Trigger a redeploy.

---

### Phase 4: Set Up Free Databases

#### 4.1 Supabase (PostgreSQL)

```bash
# Visit supabase.com
1. Create project
2. Copy connection string: postgresql+asyncpg://...
3. Set as POSTGRES_URL in Koyeb
```

#### 4.2 MongoDB Atlas

```bash
# Visit mongodb.com/cloud/atlas
1. Create free cluster
2. Create database user
3. Allow all IPs (0.0.0.0/0)
4. Copy connection string: mongodb+srv://...
5. Set as MONGO_URL in Koyeb
```

#### 4.3 Upstash Redis

```bash
# Visit upstash.com
1. Create Redis database (free tier)
2. Copy connection string: redis://...
3. Set as REDIS_URL in Koyeb
```

## Common Issues & Fixes

### Issue: Build fails on Vercel

**Solution:**
```bash
# Test locally
cd frontend
npm install
npm run build
npm run preview
```

### Issue: API requests fail with CORS error

**Solution:**
1. Check `CORS_ORIGINS` in Koyeb includes your Vercel URL
2. Check `VITE_API_BASE_URL` in Vercel points to Koyeb
3. Redeploy both services

### Issue: Database connection fails

**Solution:**
1. Verify connection string format
2. Check firewall allows connections
3. Test connection string locally

### Issue: "No module named" error in Koyeb

**Solution:**
- Ensure `requirements.txt` has all dependencies
- Redeploy
